# SBM Furniture Website

A multi-page furniture store website developed as part of a Web Development Internship at Brainery Spot Technology.

## Features

* Home Page
* Gallery Page
* About Us Page
* Contact Us Page
* Registration Page
* Product Showcase
* User-Friendly Navigation
* Responsive Design Elements

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Purpose

The project was created to demonstrate front-end web development skills by designing a furniture store website with multiple pages, product displays, and customer interaction features.
